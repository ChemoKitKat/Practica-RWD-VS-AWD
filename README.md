# Práctica: Evaluación de Rendimiento RWD vs. AWD

##  Requisitos Previos

Antes de ejecutar este proyecto, asegúrate de tener instalado en tu computadora:

* [Node.js](https://nodejs.org/) (Versión 16.0 o superior)

---

## Instrucciones de Instalación y Ejecución Local

Sigue estos pasos para clonar e iniciar el proyecto en tu máquina local:

### 1. Clonar el repositorio
```bash
git clone [https://github.com/tu-usuario/Practica-4-RWD-vs-AWD.git](https://github.com/tu-usuario/Practica-4-RWD-vs-AWD.git)
cd Practica-4-RWD-vs-AWD
```
### 2. Instalar dependencias
```bash
npm install
```
### 3. Iniciar servidor
```bash
npm start
```
